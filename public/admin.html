📱 EcoCash Integration Status

To go LIVE with real EcoCash:
1. Get merchant code from Econet Cassava
2. Set env: ECOCASH_MERCHANT_CODE, ECOCASH_API_KEY, BASE_URL
3. Endpoint: POST /api/ecocash/deposit {phone, amount, userId}
4. EcoCash will call POST /api/ecocash/callback {reference, status, amount}
5. Current mode: MOCK - auto-completes deposits

Example real call:
curl -X POST https://yourapp.com/api/ecocash/deposit -H "Content-Type:application/json" -d '{"phone":"0771234567","amount":5,"userId":"abc"}'
