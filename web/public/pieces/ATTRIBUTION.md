# Chess piece artwork

The twelve SVGs in this directory are the **Colin M. L. Burnett** chess set — the
Staunton-style vector set used by Lichess and widely known as the classic
"chess.com look".

| Field | Value |
| --- | --- |
| Author | Colin M. L. Burnett |
| Upstream | <https://github.com/lichess-org/lila/tree/master/public/piece/cburnett> |
| Origin of the originals | Wikimedia Commons `Chess_<piece>t45.svg` |
| Licence | triple-licensed: GPL-2.0-or-later, BSD-3-Clause, CC-BY-SA-3.0 |
| Licence used here | **BSD-3-Clause** |
| Files | `wK wQ wR wB wN wP bK bQ bR bB bN bP` (`.svg`) |
